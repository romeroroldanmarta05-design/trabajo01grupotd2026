**Curso:** 2026/2027  
**Universidad:** Universidad de Sevilla

## Descripción del trabajo

En este repositorio se recoge el trabajo grupal sobre los métodos de decisión bajo incertidumbre.

El trabajo consiste en reunir los problemas elaborados individualmente por cada integrante del grupo y resolverlos utilizando las funciones R proporcionadas en la asignatura.

Cada problema incluye cinco preguntas de verdadero o falso, cuyas respuestas se justifican en el documento de soluciones.

## Organización del trabajo

Para realizar el trabajo, cada integrante se ha encargado de elaborar sus dos problemas individuales, incluyendo los enunciados, las preguntas y sus correspondientes soluciones.

Hemos utilizado un repositorio compartido de GitHub para reunir todos los problemas en dos documentos comunes: uno con los enunciados y otro con las soluciones.

Cada integrante incorpora su parte desde RStudio, utilizando Git para registrar los cambios y subirlos al repositorio. Además, utilizamos las issues de GitHub para organizar las tareas pendientes y revisar el trabajo antes de la entrega.

Finalmente, revisamos entre todos la estructura de los documentos y su presentación en HTML y PDF.

## Contenido del repositorio

- `enunciados.qmd`: enunciados y preguntas de los problemas del grupo.
- `soluciones.qmd`: enunciados, resoluciones y respuestas justificadas.
- `enunciados.html` y `soluciones.html`: documentos en formato HTML.
- `enunciados.pdf` y `soluciones.pdf`: documentos PDF generados mediante Typst.
- `teoriadecision_funciones_incertidumbre.R`: funciones R utilizadas para resolver los problemas.

## Herramientas utilizadas

Para el desarrollo del trabajo hemos utilizado R y RStudio, Quarto para elaborar los documentos, y Git y GitHub para el trabajo colaborativo y el control de versiones.
